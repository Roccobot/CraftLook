# Upstream renderers

ArtCraft Quick Look packages the universal macOS CLI releases listed below. Each renderer's complete upstream documentation and notices ship in `ArtCraft Quick Look.app/Contents/Resources/Notices/<name>/`. This includes font licenses and VectorCraft's nested PDF backend licenses.

| DesignCraft | [0.20.1](https://github.com/storytold/designcraft/releases/tag/v0.20.1) | `a178783b31e1af48f7af2b516568ec85537a484dfbcc5057b0f03cadee90c0ab` |
| VectorCraft | [0.24.1](https://github.com/storytold/vectorcraft/releases/tag/v0.24.1) | `7f0c8261e5c831d9681e48272f9ba73bf8702dbf6ceb84f98177c7c007faddf2` |
| TextureCraft | [0.6.1](https://github.com/storytold/texturecraft/releases/tag/v0.6.1) | `80a65494a740d100797d54a55c43ff32ee40ee19678eebae8200f52cbba33bdc` |

The upstream notices offer the ArtCraft renderer code under MIT or Apache-2.0 and identify separate terms for third-party components and ArtCraft branding. The macOS build signs local copies of the CLI executables as part of signing the application.
