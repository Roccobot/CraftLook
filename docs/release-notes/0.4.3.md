# CraftLook 0.4.3

CraftLook 0.4.3 (build 15) fixes Space-bar previews of SVG files. If you have CraftLook 0.4.0 or later, it arrives by itself: CraftLook asks before installing it, or choose **Check for Updates...** in the CraftLook menu.

## Fix

- **SVG previews from VectorCraft.** Pressing Space on an SVG file now shows the same VectorCraft rendering as the Finder thumbnail, fitted to the Quick Look window, instead of macOS's built-in WebKit preview. That system preview used a fixed 1048 x 768 viewport, so a tall drawing was cropped to the top, and text in a missing font fell back to Times.
- **Linked images in the same folder.** When an SVG file references a local image with `href` or `xlink:href` (a same-folder file name, not a path or a URL), CraftLook includes it in the thumbnail and in the preview, if the extension can read it. If it cannot, VectorCraft leaves its own placeholder.

## Known limits

- If the font named in the SVG isn't available, VectorCraft draws the text in Source Sans 3. On this release that is the fallback for families such as Roboto when they are not installed under that exact name.
- CSS `clip-path` (for example `inset(0 round 26)`) is not applied.

## Install

Download **craftlook-0.4.3-macos.zip** (about 720 MB), unzip it, move **CraftLook** into **Applications**, and open it once. The app targets **macOS 13 or later** on Intel and Apple silicon, and needs no ArtCraft app installed. With 0.4.0 or later installed, the update arrives by itself.

**Upgrading from ArtCraft Quick Look 0.2.5?** Quit it and delete it from **Applications** before you install CraftLook, so that the two don't handle the same files.
