# CraftLook 0.5.1

CraftLook 0.5.1 (build 16) fixes the problems found in a review of 0.5.0. It is for Apple silicon (M1 or later) running macOS 13 or later. If you have CraftLook 0.4.0 or later on an Apple silicon Mac, it arrives by itself: CraftLook asks before installing it, or choose **Check for Updates...** in the CraftLook menu. Intel Macs stay on 0.4.2.

## Fixes

- **SoundCraft sessions can no longer stop the previews.** A `.scraft` file with an impossible value, such as a huge position or a sample rate near zero, made both Quick Look extensions quit every time Finder showed its folder. Each value is now brought into a sensible range, and the timeline is drawn.
- **Linked images in SVG files.** A linked file can no longer replace the drawing CraftLook renders, whatever its name. CraftLook reads at most 32 linked files and 64 MB in all, so a drawing that links to many large files can't slow Finder down.
- **Faster failure for FigCraft and DesignCraft.** When the renderer can't draw a project, the Space-bar preview falls back to the saved image right away, instead of trying the renderer a second time.
- **Sharper small previews.** A preview smaller than the screen now opens at its real size on Retina displays, instead of twice as large.
- **Busy folders.** When many thumbnails are waiting, a request with too little time left no longer starts a renderer that would be stopped at once.
- **SolidCraft 0.47.0.** The bundled SolidCraft renderer is the latest version.

## For builders

- The build without renderers now hands SVG files and renderer-only formats back to macOS's own previews.
- The checks now fail on a crash, test damaged SoundCraft sessions, linked SVG files, a renderer that runs past its time limit and the release scripts. The README lists the commands.
- The release script stops if it can't read the published appcast, instead of publishing one without the earlier versions.

## Install

Download **craftlook-0.5.1-macos.tar.xz**, double-click it to decompress it, move **CraftLook** into **Applications**, and open it once. The app targets **Apple silicon (M1 or later)** with **macOS 13 or later**, and needs no ArtCraft app installed. With 0.4.0 or later installed on Apple silicon, the update arrives by itself.
