# CraftLook 0.4.2

CraftLook 0.4.2 (build 14) is a small fix. If you have CraftLook 0.4.0 or 0.4.1, it arrives by itself: CraftLook asks before installing it, or choose **Check for Updates...** in the CraftLook menu.

## Fix

- **Open System Settings.** The button that opens the Quick Look extensions now uses the name the app has had since macOS 13, System Settings, instead of the old System Preferences. It works as before.

## Install

Download **craftlook-0.4.2-macos.zip** (about 720 MB), unzip it, move **CraftLook** into **Applications**, and open it once. The app targets **macOS 13 or later** on Intel and Apple silicon, and needs no ArtCraft app installed. With 0.4.0 or later installed, the update arrives by itself.

**Upgrading from ArtCraft Quick Look 0.2.5?** Quit it and delete it from **Applications** before you install CraftLook, so that the two don't handle the same files.
